# YoFsociety - Terminal AI 🚀

YoFsociety is a lightweight, zero-cost Terminal AI designed for developers and ethical hackers, featuring an Amharic-English language responding Assistant persona powered by OpenRouter.

## 🛠️ Installation

```bash
git clone https://github.com/yosephalganeh-cloud/YOF.git
cd YOF
pip install -r requirements.txt
python main.py
